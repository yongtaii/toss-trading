# PAPER/LIVE 연결 상태

보존한 전략은 기본 전략과 목표 투자 비중 90·95·99·100%의 주간 SMA20/200
다섯 가지다. 현재 실행 경로는 `research/`의 오프라인 백테스트뿐이다.

이전 VWAP·돌파 전략의 실행 코드와 전용 배포·검증 절차는 제거했다.
`config/strategy.toml`은 공통 API·원장을 위한 `research_only` 자리표시자다.
PAPER runner는 브로커 접속 전에 중단하고, LIVE 전략 로딩도 명시적으로 거부한다.
과거 전략을 대신 실행하거나 연구 명세 JSON을 LIVE 설정으로 해석하지 않는다.

공통 주문·체결 반영·계좌 대조·복구·제어 기반 코드는 보존했지만, 다섯 전략의 일봉 이력,
주간 일정, 추가 매수·부분 매도 원가, 다음 시가 청산 규칙은 아직 실행기에 연결하지 않았다.
연결 개발과 실제 배포는 사용자의 추후 요청으로 진행한다.

이번 정리에서는 증권사 API 호출·실주문·서버 배포·원장 삭제를 수행하지 않았다.
