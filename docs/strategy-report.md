# 남긴 전략과 투자 비중 비교 (2026-11-03)

사용자 요청에 따라 기존 주간 판단형과 고비중 변형을 비교했다. 아래 수익률은 모두
**초기 전체 계좌 $1,490 대비 비용 차감 후 손익**이며 현금도 분모에 포함된다.
매년 별도 $1,490에서 시작한다. 2025·2026년 수치는 연간 수익률로 환산하지 않았다.

### 비교 규칙

기존 종목 목록과 일봉 SMA20/200 상승 신호를 유지했다. 실제 매수 대상은 상승 신호가
있는 SOXL·TQQQ이며, 신호가 없으면 현금으로 대기한다. 주 첫 실제 거래일 시가에
전체 계좌의 목표 비중을 적용한다. 두 종목에 신호가 있으면 절반씩, 한 종목만 신호가
있으면 그 한 종목에 목표 금액 전부를 배정한다. 월요일 휴장이면 그 주 첫 거래일이다.

고비중형에서는 기존의 진입당 $298 한도와 0.5% 위험 예산을 제거하고, 매주 목표 비중에
맞춰 일부 매도·추가 매수한다. 매도를 먼저 실행하고 남은 현금 안에서만 정수 주식을
매수하며 차입하지 않는다. 따라서 **기존형 대비 비중뿐 아니라 주간 재조정도 바뀐다.**
추가 매수 시 가중평균 진입가로 손익 기준을 갱신하지만 최초 진입일·보유 나이는
유지한다. 일부 매도는 취득원가·매수 수수료를 비례 배분한다.

종가 기준 -6% 손절·+18% 익절을 감지한 다음 거래일 시가에 청산한다. 최대 보유는
20거래일이며, 주중 청산 후에는 다음 주 첫 거래일까지 신규 진입을 기다린다. 주 첫날
청산·재진입은 허용한다. 이 종가 감지 방식은 장중 손절이나 손실 6% 보장이 아니다.
갭 하락 시 손실이 커질 수 있다. 추가 매수는 평균 진입가를 바꾸므로 후속 청산 경로도
기존형과 달라질 수 있다.

편도 수수료 10bp, 슬리피지 5bp, 반스프레드 0.5bp와 매도 부과금
0.206bp(최소 $0.01)를 적용했다. 비용 2배는 매도 부과금을 제외한 수수료·마찰을
두 배로 하여 수량까지 다시 계산한다. 배당 현금·환율·세금·현금 이자는 제외한다.

대비 약 46~50% 하락했다. 기존형의 낮은 낙폭을 고비중에서도 유지한 결과가 아니다.
기존형의 완료 매매는 33건, 고비중 네 정책은 각각 50건이다. 부분 매도는 이 완료 매매
횟수에 별도 추가하지 않으며, 전체 체결·부분 매도 기록은 원장에 보존했다.

### 저장 위치와 재현

| 정책 | 보존 명세 |

| 목표 95% | `research/picks/target95.json` |
| 목표 99% | `research/picks/target99.json` |
| 목표 100% | `research/picks/target100.json` |

계산 코드는 `research/weekly_baseline.py`, `research/compare_weekly_allocations.py`,
공통 자료 검증은 `research/daily_data.py`, 별도 원장 검산은
`research/weekly_baseline_audit.py`, `research/audit_weekly_allocations.py`다.
Git에는 소형 비교 지표를 `research/results/weekly-comparison.json`으로 남기고,
원본 가격·전체 체결 원장은 `.gitignore`의 `data/` 아래에 둔다.

```sh
uv run python -m research.compare_weekly_allocations --output data/weekly-comparison-new-run
uv run python -m research.audit_weekly_allocations data/weekly-comparison-new-run
```

다른 경로에 저장된 원본 자료는 첫 명령의 `--history-dir /absolute/path/to/history`로
지정한다. 이전 평가 결과 파일 없이도 실행할 수 있다. 필요한 네 CSV 및 메타데이터는
README에 나열했다. 첫 실행에 원본 자료가 없으면 먼저 다운로드해야 한다.

이전 VWAP·평균회귀·RSI·돌파·분봉 단타·일별 후보·매수 후 보유·10% 대조군의
실행 코드·설정·전용 탐색기·전용 테스트·과거 전략 문서는 제거했다. 남긴 다섯 전략은
오프라인 연구용이다. `config/strategy.toml`은 공통 API·원장을 위한 비매매 자리표시자이며
실제 주간 전략 설정이 아니다. 이전 PAPER 실행 및 LIVE 전략 로딩은 명시적으로 거부한다.
공통 조회·시세 다운로드·리스크·체결·계좌 대조·원장 기능은 유지한다.

### 정리 후 확인

다섯 전략 × 다섯 기간 × 두 비용 조건의 50회 전체 결과를 정리 전 저장 결과와
대조했다. 수익률뿐 아니라 체결·수량·실현손익·일별 평가액·투자 비중까지 정확히 같았다.
별도 검산기도 50회와 고비중형의 반복 체결 2,515행을 확인했다. 이는 반복 평가를
포함한 행 수이며 독립 거래 표본 수가 아니다.

새 Python 3.12 가상환경에서 `uv sync --frozen`, 전체 pytest 155개,
Ruff 검사·포맷 검사, `uv build`, `git diff --check`가 통과했다.
삭제 전략의 전용 테스트는 제거했고, 휴일 주간 진입·주중 청산 후 재진입 대기·
무신호 현금 대기·삭제 전략 실행 거부와 공통 조회·원장·체결 테스트를 유지했다.
커밋·push·서버 배포·실주문은 수행하지 않았다.
